# Wyniki pomiarów

Surowe wyniki eksperymentów, po jednym folderze na etap (oznaczenia jak w planie badań):

| Folder | Etap | Opis |
|---|---|---|
| `E4/` | E4 – kryptoanaliza GPU | testy wydajności Hashcata, informacje o karcie i trybach, podsumowania |

Pliki tekstowe zapisane w Windows PowerShell (UTF-16) są konwertowane do UTF-8, aby były czytelne w przeglądarce.
Opracowane wyniki z interpretacją: katalog `docs/`.
