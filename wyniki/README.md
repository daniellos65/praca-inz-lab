# Wyniki pomiarów

Surowe wyniki eksperymentów, po jednym folderze na etap (oznaczenia jak w planie badań):

| Folder | Etap | Opis |
|---|---|---|
| `E4/` | E4 – kryptoanaliza GPU | pomiar 1 (22.10): testy wydajności Hashcata, informacje o karcie i trybach |
| `E4/pliki-testowe-parametry.txt` | E4 – kryptoanaliza GPU | parametry własnych plików testowych KeePassXC |
| `E4/veracrypt/` | E4 – kryptoanaliza GPU | pomiar VeraCrypt: wpływ PIM (liczby iteracji) na prędkość, z logiem karty |
| `E4/pomiar1-powtorka/` | E4 – kryptoanaliza GPU | powtórka pomiaru 1 (23.10) z logiem temperatury, taktowania i mocy karty |

Pliki tekstowe zapisane w Windows PowerShell (UTF-16) są konwertowane do UTF-8, aby były czytelne w przeglądarce.
Opracowane wyniki z interpretacją: katalog `docs/`.
